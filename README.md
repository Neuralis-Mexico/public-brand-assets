# ⚠️ REPO PÚBLICO — public-brand-assets

> **Este repositorio es PÚBLICO.** Cualquier persona en internet puede ver y descargar todo lo que haya aquí.
> **Solo** se sube material de marca pensado para ser público.
>
> 🚫 **NO subir:** código, documentos internos, datos de clientes, contratos, contraseñas, tokens ni llaves de API.

## Para qué sirve

Hospeda los recursos de marca de **Neuralis** que necesitan una URL pública (por ejemplo, imágenes de las firmas de correo), servidos con GitHub Pages:

`https://neuralis-mexico.github.io/public-brand-assets/<ruta-del-archivo>`

## Reglas para no romper las firmas

1. **No borres ni renombres** archivos que ya estén en uso: las firmas de correo enviadas apuntan a estas URLs y se verían rotas.
2. **Para actualizar una imagen, súbela con un nombre nuevo** (por ejemplo `firma-axel-neuralis-v2.gif`) y actualiza la firma. Gmail y otros clientes guardan en caché la imagen anterior.
3. Mantén cada GIF de firma por debajo de ~500 KB.
4. Agrega cada archivo nuevo a la tabla de **Contenido**.
